# Validación del teléfono

El sistema verifica que el valor ingresado contenga únicamente números.

# Comportamiento esperado

Saceptan números del 0 al 9.
No se permiten letras.
No se permiten espacios.
No se permiten símbolos especiales como "-", "(", ")" o "+".

# Mensaje de error

Si el valor ingresado no cumple con el formato requerido, el sistema mostrará un mensaje indicando que el teléfono debe contener únicamente números.
